# Data files

This directory is reserved for datasets needed by the notebooks.

The supplied ZIP did not contain the CSV datasets or CyAN GeoTIFF reference rasters. The dataset-generation notebook expects input files including a previously generated CSV and CyAN `.tif`/`.tiff` rasters. Review the paths and configuration cells in `notebooks/01_dataset_generation.ipynb` before running it.

Large datasets are ignored by Git. Do not commit restricted, private, or very large source data. Add documented download instructions or use a suitable data-hosting service when the data can be shared.
